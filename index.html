Architecture d'Industrialisation : Intégration Odoo & Inventaire Flottant

Cadre méthodologique pour le mémoire d'étude en Revenue Management & Systèmes d'Information

1. Odoo Property Management

Gestion des Lots & Contrats

Dans Odoo, chaque appartement de la résidence est un objet avec un statut en temps réel : Occupé Senior Permanent, Bail Étudiant, Séjour Découverte ou Vacant.

2. Passerelle API (JSON-RPC)

Synchronisation Automatisée

Un script Python gratuit (exécuté chaque nuit via GitHub Actions ou cron) interroge l'API Odoo pour isoler les lots vacants et alimente l'onglet Google Sheet Inventaire_Apparts.

3. RMS Zénao (Cet Outil)

Arbitrage & Distribution

L'algorithme RMS calcule la capacité résiduelle, applique les règles de yield (prix, MLOS) et renvoie les tarifs optimaux vers le channel manager (Booking, Airbnb).

// Modèle de Flux de Données (Data Flow Architecture)
[Résident Senior Permanent] ──> Bloque le lot dans Odoo ──> Retiré de l'inventaire Zénao
[Séjour Découverte Senior] ──> Priorité absolue LTV ──> Préempte la chambre hôtelière
[Logement Résiduel Vacant] ──> Déversé dans le RMS ──> Arbitrage TO vs PM via l'algorithme
[Contrat Corporate / Étud.] ──> Test Displacement Cost ──> Accepté si Marge nette > GOPAR Zénao
